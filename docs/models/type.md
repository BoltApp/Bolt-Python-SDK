# Type

Determines if item is a physical, digital, or bundled good, or if the good type is unknown.

## Example Usage

```python
from bolt_api_sdk.models import Type

value = Type.BUNDLED
```


## Values

| Name       | Value      |
| ---------- | ---------- |
| `BUNDLED`  | bundled    |
| `DIGITAL`  | digital    |
| `PHYSICAL` | physical   |
| `UNKNOWN`  | unknown    |

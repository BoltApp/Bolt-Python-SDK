# MerchantStatus

The merchant's status:
  * `1` - Active
  * `2` - Inactive
  * `3` - Offboarding


## Example Usage

```python
from bolt_api_sdk.models import MerchantStatus

value = MerchantStatus.ONE
```

| Name    | Value   |
| ------- | ------- |
| `ONE`   | 1       |
| `TWO`   | 2       |

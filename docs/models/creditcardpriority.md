# CreditCardPriority

Used to indicate the card's priority. '1' indicates primary, while '2' indicates a secondary card.

## Example Usage

```python
from bolt_api_sdk.models import CreditCardPriority

value = CreditCardPriority.ONE
```


## Values

| Name  | Value |
| ----- | ----- |
| `ONE` | 1     |
| `TWO` | 2     |
